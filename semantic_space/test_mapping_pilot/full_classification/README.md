# 全量测试入口分类

本表覆盖 31,968 个源码级测试入口，每项保留仓库、文件、定义位置、源码版本、目前所属环节、检查关系和已核对的验证单元。`all-entries.tsv` 为完整清单，`page-details.json` 为进度页使用的检查摘要，`summary.json` 为可重算统计。

本次有 28,871 项提取到了检查关系，包含数值误差、值相等、形状、精度类型、数量、异常、模拟调用等；同一测试允许多个类别。这些关系描述断言写了什么。9,247 项另外完成了调用对象、输入条件与实际断言的源码核对，已映射到具体系统性质。其余记录保留待展开的辅助检查、其他语言检查或尚未定位的检查内容，不自动升级为性质已确认。

测试入口所在文件与实际定义文件分别保存哈希，适用于继承测试。原始表达式和完整条件在本地的 classified-contracts.jsonl 中；公开页面只保留摘要和源码位置。此过程没有执行上游测试，绿色代表源码归类确认。

本轮新增 391 项性质映射，增加专家检查点筛选、卸载接收与请求去重、卸载统计、背压恢复、张量打包、异步传输缓冲生命周期六个单元。目前新增单元的源码证据来自 vLLM，并明确记录框架范围；跨框架统一映射继续由源码对照支持。
