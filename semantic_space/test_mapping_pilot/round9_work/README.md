# 全量源码审查材料

审查范围为锁定快照中的全部 31,968 条索引记录。各目录保存分工审查的累计结果；`crosswalk.tsv` 与 `proposed-crosswalk.tsv` 的每行对应一个具体入口，记录实际检查性质、断言位置及适用条件。新性质先提交定义，再合入空间；提取出的调用和名字不自动计为已确认归类。

`build_round9_crosswalk.py` 核对入口身份、固定源码哈希、断言位置和已登记的验证单元，产生公开映射与逐项回执。`audit_full_delivery.py` 对全量清单重新核算。此处记录的是源码审查，运行证据仍单独保存在 `background_evidence/`。

原始源码摘要、待审文件和已读未映射材料保留在各目录；辅助文件、未实现断言及只完成搭建的测试，不计入绿色归类数量。阶段结论见仓库 `docs/` 中的更新说明。
